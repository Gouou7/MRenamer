## 界面布局

顶部工具栏：左边包含菜单栏，右边为快速工具按钮。

操作栏 (规则栏)
    - 左侧为重命名操作栏。包含可用的所有重命名操作。
    - 中侧为执行操作栏。包含要执行的重命名操作，按顺序运行。
    - 右侧为配置栏。对选中的执行操作进行详细配置。

预览栏：预览原始文件名和目标文件名等信息。

状态栏：左侧左对齐显示对象数量，中间居中显示信息提示。

## 设置

提示：`<默认>` 指默认的设置项，而不写入设置项的标题中；为每个节标题添加适当符号

节标题：通用
    设置项：外观
        Native Select
            - 深色
            - 浅色
            - 跟随系统 <默认>
    设置项：语言
        Native Select
            - 中文简体
            - English
            - 跟随系统 <默认>

节标题：添加偏好

    设置项：添加文件夹内项目偏好
        Checkbox:
            - 包含文件
            - 包含文件夹
            - 递归

节标题：变量

    项目：可用变量
        Accordion 折叠的变量展示
